# Ella Healing Space

Website for Ella Healing Space — an open space for slowing down, reconnecting, and living simply, in North Evia, Greece.

## Files

```
index.html      the whole site (one page, inline styles)
assets/         photos and logo
```

No build step, no dependencies. Fonts (Figtree, Open Sans) load from Google Fonts.

## Publishing with GitHub Pages

1. Upload these files to the repository root.
2. Settings → Pages → Source: **Deploy from a branch** → `main` / `/ (root)`.
3. The site goes live at `https://<user>.github.io/ellashealingspace/`.

## Editing

- **Text** — open `index.html` and edit directly.
- **Photos** — replace files in `assets/` keeping the same filenames, or add new ones and update the `src` paths.
- **Slideshows** — sections marked `data-slideshow` crossfade through their `<img>` children. Add or remove `<img>` tags to change what cycles.
- **Contact** — WhatsApp and Instagram links appear in the hero, glamping, volunteering, and contact sections. Search for `wa.me` and `instagram.com` to update.
